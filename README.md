# WaterSaverAI
WaterSaver: AI-Powered Water Conservation Assistant using Prompt Engineering and Local LLMs. WaterSaver is an intelligent water conservation chatbot designed to help Indian households reduce domestic water consumption through personalized, AI-powered guidance. 
The application 
leverages prompt engineering and open-source language models (Ollama + Llama 3.2) 
to provide contextual water-saving tips tailored to individual family profiles, 
home types, and conservation goals.

The system addresses SDG 6 (Clean Water & Sanitation) and SDG 12 (Responsible consumption and Production) 
by enabling sustainable behavior change through an interactive, gamified interface 
that tracks water and cost savings. With zero API costs and privacy-first design, 
WaterSaver demonstrates how responsible AI can scale sustainability solutions 
to millions of households.

Key Features:
• Prompt Engineering for personalized responses
• Intent detection and context-aware recommendations
• Real-time impact tracking (liters, ₹, CO₂ reduction)
• Gamification system (score, badges, challenges)
• Fallback mechanism ensuring offline functionality
• Responsible AI (transparency, fairness, privacy)

Technologies: Streamlit, Python, Ollama, Prompt Engineering, NLP
